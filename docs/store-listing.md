## Full Description
Mute Point is a privacy-first safety app designed to help you practice assertive communication and monitor conversation dynamics.

**Features:**
- Practice assertive communication with guided exercises
- Monitor conversations for interruptions and speaking patterns
- Keep a private, encrypted journal of interactions
- Track insights over time with session analytics
- Stealth design — appears as "My Notes & Ideas"

**Privacy:**
- All data encrypted on-device (SQLCipher + Android Keystore)
- No data sent to external servers except when using Safe Rooms
- No analytics, no tracking, no ads
- No account required

**Safety:**
- PIN-protected access with panic gesture
- Screenshot blocking (FLAG_SECURE)
- Emergency exit clears all traces
